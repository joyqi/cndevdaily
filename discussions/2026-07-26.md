### 文章摘要

**Maybe we should revisit microkernels**
> 文章指出，微内核架构虽在安全、可靠和模块化上优势显著，但过去因频繁上下文切换导致性能开销过高而难以普及。如今，借助普遍集成的 IOMMU 和原子比较交换操作，可通过共享内存队列实现零开销的异步进程间通信，从根本上消除了传统瓶颈，使微内核方案重新获得可行性与实用价值。这一创新让系统能基于现有虚拟化技术构建，在兼顾高性能的同时，真正兑现驱动隔离与故障局部化的承诺。

**Watching Go's new garbage collector move through the heap**
> 文章通过perf性能分析和堆地址空间可视化，直观展示了Go 1.26中默认启用的Green Tea垃圾回收器如何利用大小分离分配提升缓存友好性，同时深刻揭示了作为非移动式收集器在回收稀疏内存页面时的固有限制，为理解现代GC的设计权衡与性能优化提供了关键技术洞察。

**Show HN: Writemark, a dependency free web component for inline Markdown editing**
> Writemark 是一个零运行时依赖的 Web 组件，只需通过 `<writemark-editor>` 标签即可嵌入任何页面，实现所见即所得的 Markdown 编辑，且始终以原始 Markdown 文本作为输入和输出值。它在单个文件中内置了源/分屏/预览模式、斜杠命令、表格、任务列表等实用功能，并通过 951 项跨浏览器自动化测试和输入模糊测试，保障了手写解析器的健壮性与安全性。
